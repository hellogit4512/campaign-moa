쿠팡 리뷰 작성기

메모·별점·배송 정보로 지시문을 만들어 복사해요. 무료 제미나이에 사진과 함께 붙여넣으면 템플릿대로 리뷰를 써 줘요. API 키도, 사용 제한도 없어요.

쿠팡 마이쿠팡 → 주문목록 → 주문 상세보기(또는 배송조회) 화면에서 Ctrl+A → Ctrl+C로 전부 복사해 붙여넣어 주세요. 이름·연락처·주소는 자동으로 지워져요.

템플릿 고치기

■ 로 시작하는 줄이 섹션 제목이에요. 섹션을 더하거나 빼면 그대로 반영돼요. 고친 내용은 이 브라우저에 저장돼요.

제미나이에서 할 일

  1. 왼쪽 버튼을 누르면 지시문이 복사되고 제미나이가 새 탭으로 열려요
  2. 제미나이 입력창의 + 버튼으로 찍은 사진을 올려요 (여러 장 가능)
  3. 입력창에 Ctrl+V로 붙여넣고 보내요
  4. 나온 제목과 본문을 복사해 쿠팡 상품평에 붙여넣어요

구글 계정으로 로그인한 무료 제미나이(gemini.google.com)를 써요. 제미나이 앱(휴대폰)에서도 같은 방법으로 돼요.
