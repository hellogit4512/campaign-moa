쿠팡 리뷰 작성기

직접 찍은 사진과 짧은 메모·별점·배송 정보를 넣으면 Gemini가 템플릿대로 상품평을 써 줘요. 메모가 비어 있으면 사진을 보고 긍정적으로 써요.

최근 쿠팡 주문

쿠팡 주문목록을 버튼 한 번으로 가져올 수 있어요 (PC 크롬·엣지).

  1. 즐겨찾기 막대가 안 보이면 Ctrl+Shift+B
  2. 아래 버튼을 즐겨찾기 막대로 끌어다 놓기 (처음 한 번만)
    쿠팡 → 리뷰 작성기
  3. 쿠팡에 로그인하고 마이쿠팡 → 주문목록을 연 뒤, 즐겨찾기의 그 버튼을 누르기

주문목록 화면에서 상품명·옵션·주문일·배송 상태만 읽어요. 이름·주소·연락처·결제 정보는 읽지 않고, 가져온 목록은 이 브라우저에만 저장돼요.

리뷰 쓸 상품을 누르면 상품명과 배송 정보가 채워져요. 새 주문은 쿠팡 주문목록에서 즐겨찾기 버튼을 다시 누르세요.

사진을 여기에 놓거나 눌러서 선택

쿠팡 마이쿠팡 → 주문목록 → 주문 상세보기(또는 배송조회) 화면에서 Ctrl+A → Ctrl+C로 전부 복사해 붙여넣어 주세요. 이름·연락처·주소는 자동으로 지워져요.
